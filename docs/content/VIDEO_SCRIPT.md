# 3-minute demo script (record only after live Hindsight verification)

**0:00–0:25 — Intro**
“I'm Abhi. This is an incident-response agent that brings verified history into a new investigation. It recommends diagnostics; it never changes production systems.”

**0:25–0:50 — The problem**
“Here is a payments API reporting 502s. A generic assistant can suggest standard checks, but it has no knowledge of how this team resolved a similar incident.”

**0:50–1:25 — First incident**
Enter the incident. Show the initial plan. Explain that likely causes are hypotheses, not facts. Enter the human-verified root cause, resolution, and runbook, then retain it.

**1:25–2:25 — Memory changes the next investigation**
Submit a similar incident. Show the recalled prior incident. Compare the new plan with the first plan and point to the specific diagnostic step informed by memory. Show that the memory comes from Hindsight, not the local demo fallback.

**2:25–2:50 — Safety and limitations**
“Similar symptoms don't guarantee the same cause. The agent treats memory as context, and an engineer verifies the current evidence. No production actions are executed.”

**2:50–3:00 — Close**
“The goal is to make each confirmed incident useful to the next on-call engineer.”
