## Social post draft (only publish after validating the project)
An incident agent is only useful if it can learn from what actually fixed the last incident.

We built a focused workflow around Hindsight:
- Recall prior incident experience
- Keep AI hypotheses separate from confirmed root causes
- Retain the engineer-verified resolution
- Reuse that context when a similar incident returns

The important part isn’t chat history—it’s whether remembered experience changes the next investigation.
